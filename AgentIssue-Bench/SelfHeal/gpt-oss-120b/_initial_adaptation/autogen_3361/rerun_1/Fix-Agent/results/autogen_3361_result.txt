+    funcs: List[Union[FunctionWithRequirements[Any, P], Callable[..., Any], FunctionWithRequirementsStr]]
+) -> str:
+    """Build a single Python file that contains all required global imports and the
+    source code of the supplied functions.
+
+    The original implementation attempted to collect the ``global_imports`` from
+    each ``FunctionWithRequirements`` (or its string counterpart) into a ``set``
+    and then map each import object to its string representation via
+    ``_import_to_str``.  However, the import objects include dataclasses such as
+    :class:`ImportFromModule` which are **mutable** and therefore **unhashable**.
+    Adding them to a ``set`` raises ``TypeError: unhashable type: 'ImportFromModule'``
+    when a user decorates a function with ``global_imports=[ImportFromModule(...)]``.
+
+    To avoid this issue we no longer store the import *objects* in a set. Instead
+    we convert each import to its string representation first and deduplicate the
+    resulting strings. Strings are hashable, so a set works as intended without
+    requiring the dataclasses to be hashable or frozen.
+
+    This change preserves the original behaviour (imports appear only once) and
+    fixes the ``TypeError`` while keeping the rest of the logic unchanged.
+    """
+
