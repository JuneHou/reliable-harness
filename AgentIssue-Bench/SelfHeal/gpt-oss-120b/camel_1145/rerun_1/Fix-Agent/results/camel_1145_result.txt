def __getattr__(name: str):

    This function is invoked by Python when an attribute lookup on the module
    fails. If the attribute corresponds to one of the lazy‑import entries we
    import the target module, cache the attribute in the module's globals and
    return it. If the import itself fails (e.g., a missing third‑party package),

        globals()[name] = attr
        return attr
